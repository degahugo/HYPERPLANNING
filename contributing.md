# Contribution

## Règles simples
- Avant de travailler : lire le ticket Jira et annoncer dans le groupe.
- Ne pas modifier les mêmes fichiers en même temps.*
- Le main ( si on push sur la branche main) contiendra uniquement du code fonctionnel
avec les tests associées sur les fonctions pour ne pas avoir de problèmes avec les fonctions.
- Vérifier que le projet compile avant de pousser.



## Convention de commits
- docs: ...
- feat: ...
- fix: ...
- chore: ...
